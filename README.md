# Halis Dede paylaşım

`takvim.json`'daki zamanı gelen gönderiyi GitHub Actions saat başı Instagram'a paylaşır (Reels + yorum + hikâye).
Her gönderi `gonderiler/<id>/` içinde: `video.mp4`, `kapak.jpg`, `aciklama.txt`, `sabit-yorum.txt`.
Paylaşılanlar `durum.json`'a yazılır. Anahtar: repo secret `IG_TOKEN`.
Elle: yorumu sabitlemek, anketli hikâye, yorumlara cevap.
